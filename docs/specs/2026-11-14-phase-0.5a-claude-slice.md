## 1. 目标

用最短路径跑通一条真实可接管的链路，只接 Claude：

```
Pi 扩展 → cp_dispatch → control-plane daemon → claude-agent-acp(ACP v2) → Claude 会话
        ← 事件流(WS/SQLite) ← transcript 只读 ← state_update / tool_call
   inject / interrupt / checkpoint / handoff(→ claude --resume 原生终端) / handback(→ ACP resume)
```

**完成定义**：Gate 0.5-A 九条全部有证据（见 §10），且整条流程连续跑通 2 次。

## 2. 非目标

Codex / Pi 托管会话 / DSH；Web UI；多用户与远程鉴权（只保留 token 校验接口）；记忆与知识库；跨 Agent 会话搬家。

## 4. 关键决策（冻结）

1. **载体**（A00 实测）：ACP `session/new` 返回的 id 就是 Claude 原生 sessionId，transcript 在 `~/.claude/projects/<mangled-cwd>/<id>.jsonl`。
2. **handoff 出口按 kind 分流**：`kind=interactive` → `claude --resume <id>`（PTY 或用户终端）；`kind=background` → `claude attach <id>`。**attach 对 ACP 会话无效**（`No job matching`）。
3. **SessionCaps.attach 与 resume 分开上报**；未实现能力不注册工具、不返回按钮字段。
4. **单 driver 硬约束**：任何 inject / interrupt / checkpoint / handoff 必须先持 lease；无 lease 只允许 see。
5. **原生 transcript 只读**：控制面只追加自己的事件库，绝不改写 Claude JSONL。
6. **SQLite 使用 `node:sqlite`**（Node 24 内置），WAL 模式；不引入 better-sqlite3 原生模块。
7. **HTTP 用 Fastify 5 + @fastify/websocket**；配置用 `yaml`；进程调用用 `execa`。
8. **ACP 版本锁定**：`@agentclientprotocol/sdk@2.6.0`、`@agentclientprotocol/claude-agent-acp@0.107.0`，`CLAUDE_AGENT_ACP_PROTOCOL=v2`。

## 5. 数据模型

数据库：`~/.pi-workbench/workbench.db`（WAL）。迁移用 `PRAGMA user_version`，v1 建四表。

```sql
CREATE TABLE sessions (
  key TEXT PRIMARY KEY,              -- 'claude:<nativeId>'
  agent TEXT NOT NULL,
  native_id TEXT NOT NULL,
  acp_session_id TEXT,
  cwd TEXT NOT NULL,
  kind TEXT NOT NULL,                -- interactive | background | unknown
  status TEXT NOT NULL,              -- starting|running|needs-input|idle|handoff|exited|unknown
  driver TEXT NOT NULL DEFAULT 'none',
  caps_json TEXT NOT NULL,
  transcript_path TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE TABLE events (
  seq INTEGER PRIMARY KEY AUTOINCREMENT,
  session_key TEXT NOT NULL,
  type TEXT NOT NULL,
  payload_json TEXT NOT NULL,
  source TEXT NOT NULL,
  ts TEXT NOT NULL,
  idempotency_key TEXT NOT NULL UNIQUE
);
CREATE INDEX idx_events_session_seq ON events(session_key, seq);
CREATE TABLE leases (
  session_key TEXT PRIMARY KEY,
  driver TEXT NOT NULL,              -- pi | human
  client_id TEXT NOT NULL,
  expires_at TEXT NOT NULL,          -- ISO
  heartbeat_at TEXT NOT NULL
);
CREATE TABLE checkpoints (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_key TEXT NOT NULL,
  path TEXT NOT NULL,                -- ~/.pi-workbench/handoffs/<key>-<ts>.md
  summary TEXT NOT NULL,
  touched_files_json TEXT NOT NULL,
  next_step TEXT NOT NULL,
  cursor TEXT NOT NULL,              -- transcript byte offset
  created_at TEXT NOT NULL
);
```

## 6. API 契约

统一前缀 `/api/cp`。错误体：`{ "error": { "code": "...", "message": "...", "details": {} } }`。

| 方法 路径 | 请求 | 响应 |
|---|---|---|
| GET `/health` | — | `{ok,name,version,pid,uptimeMs}` |
| GET `/agents` | — | `[{agent, available, version, caps}]` |
| GET `/sessions?agent=&status=` | — | `SessionRef[]` |
| GET `/sessions/:key` | — | `{session: SessionRef, lease: Lease\|null}` |
| GET `/sessions/:key/transcript?after=&limit=` | — | `{messages: UnifiedMessage[], nextCursor: string}` |
| POST `/sessions/:key/lease` | `{action:"acquire"\|"release"\|"heartbeat", driver, clientId, ttlMs?}` | `Lease` |
| POST `/sessions/:key/inject` | `{text, clientId}` | `{messageId, effective:"now"\|"next_turn"}` |
| POST `/sessions/:key/interrupt` | `{clientId}` | `{stopReason}` |
| POST `/sessions/:key/checkpoint` | `{summary, touchedFiles, nextStep}` | `Checkpoint` |
| POST `/sessions/:key/handoff` | `{to:"human"\|"pi"}` | `{checkpoint, command: string[], mode:"resume-tui"\|"attach"}` |
| POST `/sessions/:key/handback` | `{clientId}` | `{resumed: boolean, deltaSummary: string}` |
| GET `/sessions/:key/checkpoint` | — | `Checkpoint\|null` |
| POST `/dispatch` | `{agent:"claude", task, cwd?, idempotencyKey}` | `SessionRef` |
| WS `/ws?after=<seq>` | — | `{seq, sessionKey, type, payload, ts}` 流 |

错误码：`E_BAD_REQUEST`、`E_UNAUTHORIZED`、`E_SESSION_NOT_FOUND`、`E_LEASE_CONFLICT`、`E_NO_LEASE`、`E_CAP_UNSUPPORTED`、`E_ADAPTER_DOWN`、`E_RESUME_REJECTED`、`E_IDEMPOTENCY_CONFLICT`。

鉴权：仅 loopback 监听时免鉴权；非 loopback 必须带 `Authorization: Bearer <token>`，否则 401 `E_UNAUTHORIZED`。

## 7. 事件模型

`SessionEvent.type`：`token | thought | tool_call | tool_result | permission_request | plan | state_update | session_status | needs_input | lease_changed | error | notice`。

- `seq` 由 SQLite 自增，全局单调；WS 重连用 `after=<seq>` 补拉。
- `idempotencyKey` = `<agent>:<nativeId>:<acp-update-id 或 hash(type+payload)>`；重复投递 `INSERT OR IGNORE`。
- 状态由事件投影：`state_update.state` → `SessionRef.status`（running / needs-input / idle）。

## 8. Claude 能力矩阵（本阶段实测口径）

| 能力 | 值 | 说明 |
|---|---|---|
| transcript | true | `~/.claude/projects/*/*.jsonl` 只读增量 |
| stream | true | `session/update` 通知 |
| inject | true | `session/prompt`（adapter 声明 `promptQueueing=true`，运行中排队，`effective="next_turn"`） |
| interrupt | true | `session/cancel` |
| resume | true | `session/resume`（运行中需先 close/stop） |
| attach | false（interactive）/ true（background） | 见 A00 |
| permissions | true | `session/request_permission`，默认自动 allow_once |
| background | false（interactive） | — |

## 9. Handoff 流程（v1，quiesce 语义）

1. 校验 lease（driver=pi）→ 2. 运行中则 `session/cancel` 并等 `idle` → 3. 写 checkpoint（摘要/触碰文件/下一步/cursor）→ 4. `session/close` 释放 adapter → 5. 返回接管命令：interactive → `["claude","--resume",nativeId]`；background → `["claude","attach",nativeId]` → 6. lease 转 `human`（TTL 默认 30 min，CLI 心跳续期）→ 7. `handback`：`session/resume` + 读 transcript 增量 → 生成 `deltaSummary` → lease 转 `pi`。

不承诺两个 driver 同时写；任何情况下不得跳过 lease。

## 10. 验收（Gate 0.5-A）

| # | 验收项 | 证据形式 |
|---|---|---|
| 1 | `cp_dispatch` 返回 SessionRef（key/agent/nativeId/cwd/status/driver/capabilities） | e2e JSONL + HTTP 响应 |
| 2 | dispatch 后 2 秒内出现事件，token 与 tool call 可见 | `/transcript` 与事件 seq |
| 3 | `cp_inject` 改变下一轮行为；无 lease 被拒 | 两次请求对比 + 401/409 记录 |
| 4 | `cp_interrupt` 让运行中 turn 进入 idle 并记录 stopReason | state_update 事件 |
| 5 | `cp_handoff(to=human)` 生成 checkpoint，且能在原生终端打开同一会话 | checkpoint 文件 + TUI 抓屏 |
| 6 | 人工一轮后 `handback` 接回，Pi 能看到新增 transcript | deltaSummary + 增量消息 |
| 7 | daemon/adapter 崩溃后租约不永久锁死 | 杀进程后 TTL 回收事件 |
| 8 | 同一会话不存在两个 driver 同时写；错误路径有错误码 | E_LEASE_CONFLICT 用例 |
| 9 | 以上连续跑通 2 次 | e2e 运行两次的 JSONL |

## 11. 风险与降级

| 风险 | 降级 |
|---|---|
| ACP adapter 崩溃或握手失败 | 报 `E_ADAPTER_DOWN`；保留 `claude --bg` 原生兜底（本阶段不实现） |
| 运行中 inject 不生效 | 退化为 turn 边界注入，响应标 `effective:"next_turn"` |
| transcript 落盘延迟 | 以"文件出现/变大"为准；无文件时返回空并标注 `pending` |
| resume 被拒（运行中） | 先 close/stop 再 resume；仍拒绝则返回 `E_RESUME_REJECTED` |
