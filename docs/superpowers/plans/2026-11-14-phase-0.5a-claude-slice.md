# Phase 0.5-A Claude 垂直切片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Pi 通过 control-plane daemon 真实驱动、观察并交接一个 Claude 会话（dispatch → see → inject → interrupt → handoff → handback）。

**Architecture:** 单个 Node daemon 持有 ACP v2 客户端（claude-agent-acp 子进程），所有会话状态落到本地 SQLite（WAL）；HTTP/WS 暴露统一 API，Pi 扩展是薄客户端；接管权限由 lease 表串行化；原生 transcript 只读增量解析，与 ACP 事件流合并成统一事件序列。

**Tech Stack:** Node 24（`node:sqlite`、`node:test`、type stripping）、TypeScript strict、Fastify 5 + @fastify/websocket、yaml、execa、@agentclientprotocol/sdk 2.6.0、@agentclientprotocol/claude-agent-acp 0.107.0。

**Spec:** `docs/specs/2026-11-14-phase-0.5a-claude-slice.md`

## Global Constraints

- Node ≥ 24，pnpm 12.3.4 workspace；TypeScript strict；不允许 `any`（必要时 `unknown` + 窄化）。
- 监听 `127.0.0.1:7331`（env `PI_WORKBENCH_HOST` / `PI_WORKBENCH_PORT` 可覆盖）；非 loopback 必须 Bearer token。
- 数据目录默认 `~/.pi-workbench`（env `PI_WORKBENCH_HOME` 可覆盖）。
- ACP 依赖版本锁定：`@agentclientprotocol/sdk@2.6.0`、`@agentclientprotocol/claude-agent-acp@0.107.0`，子进程环境 `CLAUDE_AGENT_ACP_PROTOCOL=v2`。
- Claude 原生 transcript `~/.claude/projects/<mangled-cwd>/<sessionId>.jsonl` **只读**，任何代码不得写入该目录。
- 单 driver：inject / interrupt / checkpoint / handoff 必须先持 lease，否则 `E_NO_LEASE`。
- 不提交 `.bak` 备份文件；提交信息用中文 `feat:/fix:/test:/docs:/chore:` 前缀。
- 测试只用 `node:test` + `node --test --experimental-strip-types`，不引入 vitest/jest。

## Review Focus

1. **transcript 尚未落盘**（A00：prompt 后 ~1.5s 目录仍为空）——读取不存在的文件必须返回空消息与 `cursor:"0"`，不得抛异常或死等。
2. **租约已过期**——TTL 到期后 `heartbeat` 必须返回 `E_LEASE_CONFLICT` 而不是静默续期，否则两个 driver 会同时写。
3. **adapter 子进程崩溃/退出**——未完成的 prompt 与后续 inject 必须立即报 `E_ADAPTER_DOWN`（5s 内），不得无限挂起。
4. **重复 dispatch 幂等键**——同一 `idempotencyKey` 二次调用返回同一 SessionRef，不同 payload 复用时返回 `E_IDEMPOTENCY_CONFLICT`。
5. **无租约的写操作**——未持 lease 直接调 inject/interrupt 返回 `E_NO_LEASE`，且不产生任何 ACP 请求。
