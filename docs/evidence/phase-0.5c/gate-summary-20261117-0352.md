## 已知偏差

1. **Claude interactive attach=false**：`POST /sessions/:key/attach` 返回 `422 E_CAP_UNSUPPORTED`。重启后"attach 200 再 inject"无法用 Claude interactive 演练，`e2e-restart` 把 422 作为负向断言保留；会话记录/transcript 不丢由同一脚本正向断言；重启后的接管改由 `POST /sessions/:key/resume` 演练，且必须先持租约（e2e-restart 断言无租约 409、取租约后 resume→inject→transcript 回显）。契约见 `docs/api/cp-v1.md` §4。
2. **Windows 优雅关闭**：Node 在 Windows 的 `SIGTERM` = `TerminateProcess`，daemon 的优雅关闭分支不可达，`e2e-faults` 的 `graceful-shutdown-ended-at` 显式 SKIP（需 POSIX + `PI_WORKBENCH_E2E_SHUTDOWN=1` 补测）。其余退出路径（`daemon-stop-exit`、`no-residual-children`、`instances-ended-at-reconciled`）已覆盖。
3. **单机单 daemon**：实例锁依赖 pid 存活判断，跨用户/容器不保证。
4. **测试 skip**：`真 adapter 冒烟（默认跳过，PI_WORKBENCH_REAL_ADAPTER=1 才跑）` 属既有设计；另有 `killAll` POSIX 进程组测试在 Windows 上按 `process.platform` 显式跳过（POSIX-only 守护）。
